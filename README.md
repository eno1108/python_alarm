# Windows Python Alarm ⏰

Windows 標準機能のみを活用し、外部ライブラリ（`pygame`, `plyer` 等）のインストール不要で動作する軽量デスクトップアラームツールです。

指定した時刻（`HH:MM`）になると、リアルタイムカウントダウンを経て **Windows トースト通知** のポップアップと **MP3/音声ファイルの再生** を行います。

---

## 主な特徴

- 🚀 **外部ライブラリ不要（Zero Dependencies）**: `pip install` や C拡張ビルドエラー（Python 3.14+ 等）に悩まされることなく、標準モジュールと Windows PowerShell 連携のみで動作します。
- 🔔 **Windows ネイティブ通知**: アクションセンターに届くトースト通知で視覚的にお知らせします。
- 🎵 **MP3/WAV 再生対応**: Windows Presentation Foundation (`presentationCore`) を呼び出すことで、追加コーデックやプレイヤーなしで音声をバックグラウンド再生します。
- ⏳ **リアルタイムカウントダウン**: ターミナル行内で残り時間を `HH:MM:SS` 形式で逐次更新表示します。
- 📅 **日付またぎ自動判定**: 指定時刻が現在時刻を過ぎている場合は翌日のアラームとして自動スケジューリングします。

---

## 動作要件

- **OS**: Windows 10 / Windows 11
- **Python**: Python 3.8 以上（3.11, 3.12, 3.14 動作確認済み）
- **PowerShell**: 5.1 以上（Windows 標準搭載）

## 使い方

### 1. リポジトリのクローンまたはダウンロード

```bash
git clone https://github.com/<your-username>/python_alarm.git
cd python_alarm
```

### 2. 音声ファイルの準備

再生したい音声ファイル（MP3 / WAV 等）を用意し、スクリプト先頭のパスを書き換えます。

```python
# アラーム.py 内
AUDIO_FILE = r"F:\music\your_alarm_sound.mp3"
```

> **Note**: Windows のパス指定でエスケープエラーを防ぐため、文字列の前に `r` を付けた raw文字列（例: `r"C:\path\to\sound.mp3"`）として指定してください。

### 3. スクリプトの実行

ターミナル（Command Prompt / PowerShell）で以下を実行します。

```powershell
python アラーム.py
```

実行後、プロンプトに従ってアラーム時刻を入力してください：

```text
アラーム時刻を入力してください (HH:MM): 07:30

2026-10-06 07:30 にアラームを設定しました。(Ctrl+C で中断)

残り時間: 06:45:12
```

### 4. アラームの停止

- **カウントダウン中**: `Ctrl + C` を押すと安全にキャンセルして終了します。
- **アラーム鳴動時**: ターミナル上で `Enter` キーを押すと音声が即時停止します。

## トラブルシューティング

| 現象 | 原因と対処法 |
| :--- | :--- |
| **通知が表示されない** | Windows の「設定」>「システム」>「通知」で通知がオフになっていないか、または「集中モード（応答不可モード）」になっていないか確認してください。 |
| **音が出ない** | `AUDIO_FILE` のパスが存在しているか、スピーカーのミュート設定が有効になっていないか確認してください。 |
| **ファイル名のエスケープエラー** | パス指定の文字列先頭に `r`（raw文字列）を付与しているか確認してください（例: `r"C:\music\song.mp3"`）。 |
